# Configuration Clone

The Configuration Clone tool copies all configuration tables from one Part Studio or Assembly into the current tab.
This tool works only on Part Studios and Assemblies. Drawings are not supported.

Copy the full URL for the source tab containing at least one configuration parameter or table.
Paste the URL into Renaissance in the destination document, then click **Clone Configuration**.
Renaissance copies all tables and parameters into the current document.

Features are not configured by this operation.
