# Remove Sketch Constraints

This application scans the current feature tree and finds Sketch features containing missing sketch constraints.
Missing sketch constraints are constraints where a referenced entity is no longer valid.
The constraint appears red in the sketch editing UI, and the sketch feature appears red in the feature tree.

Select the sketch features to remove constraints from, then click **Remove missing constraints**.
Affected features are edited to remove constraints where the reference entity is missing.

**Remove All Constraints** removes all constraints from a sketch instead of only missing or bad constraints.
