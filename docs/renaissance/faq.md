# FAQ

## What is Renaissance?

Renaissance is a collection of automation tools for Onshape that helps reduce manual work and minimize errors across assembly, part, drawing, and document workflows.

## How do I start using Renaissance?

Start from the [Renaissance overview](index.md) and choose the tool category that matches your workflow:

- [Assembly](assembly/index.md)
- [Part](part/index.md)
- [Drawing](drawing/index.md)
- [All Contexts](all/index.md)

## Why are some exports slow?

Including drawings or sheet metal flat patterns can significantly increase export time. Well-organized documents, especially one part per document, help reduce the time Renaissance spends finding related drawings.

## Why was a drawing not included in Assembly Export?

Renaissance only exports drawings that reference the selected part and the matching configuration. If the assembly uses a configuration that is not shown in a drawing view, that drawing will not be exported.

## Why were flat patterns not exported?

Flat patterns are only exported for sheet metal parts that have an Onshape-generated flat pattern.

## Can Renaissance email export results to me?

Yes. Several tools support email delivery. When that option is enabled, Renaissance sends the current user a download link after processing completes.

## I can't find my files

Files that are not emailed to are uploaded to the default workspace in the document renaissance was run from.


## Are all tools available in every Onshape context?

No. Some tools are specific to assemblies, parts, or drawings, while others work across multiple contexts. Use the category pages to find the tools that apply to your current document.
